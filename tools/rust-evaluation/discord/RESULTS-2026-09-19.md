# Serenity / discord.js offline replay — 2026-09-19

This is a bounded application evaluation, not a replacement bot or a Gateway memory
benchmark. Serenity is pinned to `86866e9a20dc441faac7b38c68a3cf78721ded1c` from `next`,
using native Components V2 builders. Native serialized components match fixtures
produced by the existing discord.js display helpers, with explicit mention controls.
Neither candidate logs into Discord or instantiates a connected Gateway client.

Both replay executables render profiles, autocomplete choices, page/session payloads
and feed messages against the same local synthetic HTTP fixture. Source GraphQL
operation documents are preserved, but responses are normalized display data rather
than real PostGraphile response models. The Rust executable currently parses the
embedded document bundle per event; the Bun comparator imports it once. Results apply
to these implementations, not a general library comparison.

Apps receive CPUs 0–1, a 512 MiB limit and no swap; fixture receives CPU 2 and 256 MiB;
loader/samplers receive CPU 3. Each attempt starts fresh processes and fixture state.
Three rounds rotate order. Individual scenarios use 15 events/s, mixed burst uses
150 events/s, and closed-loop capacity uses concurrency 32. Session capacity is 256;
TTL is shortened identically to 15 seconds, with a 75-second recovery window covering
expiry and the normal 60-second cleanup timer. These rates are synthetic assumptions.

The fixture validates delivery ordering and tracks duplicate sends and persisted feed
cursors. Separate fault checks passed for transient 429/500 and permanent DM failure:
only two successful deliveries advanced two cursors. Retry delays in this fixture
are fixed, not Discord's production bucket/global rate-limit behavior. File component
goldens cover serialization, not uploads. Full commands, actual WebSocket transport,
reconnect/catch-up and production parity remain [deferred gates](README.md).

Do not extrapolate these results to connected bot memory, Discord rate limits or
network latency. Application PSS/RSS, fixture memory and cgroup working set are
reported separately. Raw results remain under ignored
`artifacts/rust-evaluation/discord/measured-2026-09-19/`.
