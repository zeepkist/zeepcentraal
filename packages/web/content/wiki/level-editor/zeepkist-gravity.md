This Zeepkist science reference was shared by **89・Pine Tree** on **23/02/2024 11:43**.

Use a fan underground pointing upward to reproduce these gravity settings:

| Location | Fan value |
| --- | ---: |
| Space | 5.585161 |
| Pluto | 5.232066 |
| Earth's Moon | 4.662559 |
| Mercury and Mars | 3.472288 |
| Uranus and Venus | 0.533629 |
| Earth | 0 (obviously) |
| Saturn | -0.360498 |
| Neptune | -0.764848 |
| Jupiter | -8.532932 |
| Sun | -150.45992 |

::content-alert{type="important" title="The Sun value is extreme"}
The original test describes **-150.45992** as far too much power. Even at **-100**, the first turn on A01 could not be completed.
::
